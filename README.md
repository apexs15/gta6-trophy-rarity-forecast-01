# gta6-trophy-rarity-forecast-01

Logit-trend forecaster for GTA VI trophy earn rates on Exophase: it fits a shrunk log-time trend per trophy on the distinct refresh points and widens the spread with the horizon and the trophy's own refresh jumps. Runs as `python3 /bot/main.py`, standard library only, deterministic, no network.
